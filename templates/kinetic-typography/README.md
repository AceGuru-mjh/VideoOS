# kinetic-typography — 纯文字动效（8s · 16:9）

两幕纯文字动效：逐字波浪入场 + 同位换词硬切（末词强调色定格）。零素材、静音可看。

## 何时用

概念短片、金句/口号传播、社媒文字卡——文字本身就是画面时。

## 怎么改

- `HERO`：波浪主词（CJK 逐字步进 ≈ 字号；拉丁字母改为 `size * 0.72`）。
- `SWAPS`：换词序列 2-3 个（末位定格为主张词，自动用强调色）；`windows` 时间表按每词约 1s 调整。
- 波浪节奏：`delay: 0.05 + i * 0.04`（错峰 0.03-0.05s 都成立）。
- 换词用 `wipe`（文本层专用）；一处只留一个波浪——两个同时错峰的组读作噪声。
