# data-dashboard — 数据看板（15s · 16:9)

三幕数据叙事：主指标大数字 count-up → 2×1 对比双卡 → 六柱阶梯生长收束到结论句。零素材、静音可读。

## 何时用

季度汇报视频、增长战报、产品数据速览、融资演示数据页。所有数字必须来自真实数据。

## 怎么改

- `HERO`：主指标（标签 / 数值 / 增幅）——一个数字独占一幕，count-up 时长按位数 1.0-1.4s。
- `DUO`：对比双卡（保持 2×1，禁 2×2——四个数字同屏等于没有重点）；增幅必须带 +/- 号。
- `STEPS`：趋势六步高度 px = round(值 × 3)；末柱自动用强调色。
- `CONCLUSION`：结论句 ≤ 16 字——阶梯不收束到一句话就是屏保。
- 数字一律 `font: "monospace"`（比例字体逐字打字会横向抖动）。
