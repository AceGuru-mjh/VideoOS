# tech-intro — 科技感片头（6s · 16:9）

单场景科技 Sting：暗色网格背景、大标题 blur-up、相机缓推、副标题，尾部 4 秒静止。零素材。

## 何时用

发布会开场、频道片头、产品预告前的品牌 Sting——只做亮相，不讲叙事。

## 怎么改

- `WORDMARK` / `TAGLINE` / `ACCENT` 三个常量：主标题（≤ 8 字符）、副标题（≤ 12 字）、强调色。
- 网格密度：两个 for 循环的上界（16 / 9），透明度保持 ≤ 0.12。
- 时长：`duration: 6` 改 5-8s 均成立；所有入场已在 2.0s 前完成，拉长只增加静止。
- 想要网格漂移感：给网格线加 `delay: 0.1 + i * 0.02` 按索引错峰。
