# comparison — 产品对比（12s · 16:9）

分屏对阵板 + 三回合逐项 PK（胜方绿勾 ✓、负方灰点 ·、比分条跳动）+ 每回合 1.2 秒定格读窗 + 裁决帧三理由。

## 何时用

产品对比测评、选型指南、功能 PK 短视频、竞品分析汇报。数字与主张必须来自真实来源。

## 怎么改

- `US` / `THEM`：双方名字；`ROUNDS`：三回合（议题、双方主张 ≤ 14 字、诚实胜者）。
- 诚实原则：让掉真的会输的一回合（示例把"价格"判给对方）——3:0 是广告不是对比。
- `REASONS`：裁决三理由（每条 ≤ 14 字）。
- 板几何全场唯一（x 27% / 73%、840×760），跨场景漂移是本类第一大 bug，别单独改某一场。
- 换更硬的节奏：四处 `crossfade` 改 `cut`。
