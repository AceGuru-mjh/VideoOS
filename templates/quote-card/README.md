# quote-card — 金句卡（8s · 1:1）

方形金句卡：巨型引号 + 打字机引文 + 关键句弹出 + 署名淡入，尾部静止 3 秒适合循环。零素材。

## 何时用

社媒金句卡、演示引用页、读书分享、活动金句海报动图化。

## 怎么改

- `LEAD_LINES` / `KEY_LINE`：引文拆「铺垫（打字机）+ 关键句（弹出）」；引文必须逐字引用，禁改写。
- `AUTHOR` / `ROLE`：署名与头衔/年份。
- 打字机节奏：每行 `duration ≈ 字数 × 0.045`，第二行 `delay` 接在第一行完成后 0.2s。
- 长引文加行：复制 lead 层并下移 y（约 9%/行），v1 文本单行绘制，多行必须拆层。
- `ACCENT` 换强调色——全卡只允许关键句一个强调色。
