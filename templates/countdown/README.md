# countdown — 倒计时（5s · 16:9）

数字 5→1 每 0.8 秒向上翻滚（旧数字向上离场 + 新数字自下升入），每窗一次脉冲光环，硬切到活动定版卡。零素材。

## 何时用

直播/活动开场、新品发布倒计时、预告片头、整点蹲守提醒。

## 怎么改

- `EVENT` / `DATE` / `CTA`：活动名（≤ 12 字符）、日期时间（必须真实，禁编造）、行动号召。
- 节奏：`0.8` 秒/位改慢（1.0s）时同步调大场景 `duration`（= 位数 × 每位时长）。
- 翻滚方向是引擎语义：`exit: slide-down`（向上离场）+ `enter: slide-up`（自下升入）；不要两个 slide-up。
- 定版卡要更长尾巴：把 `lockup` 场景 `duration` 改 2-3s（元素 0.2s 内已全部落定）。
