# product-intro — 产品介绍（30s · 16:9）

五幕结构：痛点钩子 → 解决方案 → 三特性逐条 → 数据证明 → CTA 定版。零素材、静音可看，开箱即编译。

## 何时用

产品发布、官网头图、落地页宣传视频——需要完整叙事而不只是片头时。

## 怎么改

- `src/video.ts` 顶部 `BRAND` / `ACCENT` / `URL` 三个常量：品牌名、主色、链接。
- `hook` 场景：换成你的用户痛点（保持 1s 内可读，≤ 14 字）。
- `features` 场景：`FEATURES` 数组换三条特性（每条 ≤ 22 字防溢出）。
- `proof` 场景：数字必须来自真实数据（`kpi-value` 等宽字体防抖动）。
- 时长调节：改各场景 `duration`（crossfade 0.5s 会使后一幕提前 0.5s 开始）。
- 改竖屏 9:16：需重排 y 坐标，且底部 20% 留给平台 UI（放字幕/点赞栏遮挡区）。
