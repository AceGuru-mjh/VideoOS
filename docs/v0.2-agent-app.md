# VideoOS v0.2 — Agent App（主线规格）

> 主线智能体执行本规格。与并行子项目 [Agent Kit](../agent-kit/SPEC.md) 的关系：**消费其产出**（model-hub 目录/工厂/诊断、mcp-host 本地工具、25 技能），**不依赖其进度**——在 Agent Kit 交付前，全部功能用内置兜底（既有 providers / 31 个 VAP 工具 / 5 技能）先行可用。

## 1. 产品定义

把 Studio 从「IDE 优先」演进为「**对话优先**」的 Agent 应用：

```
首次启动 ─▶ 第 1 屏：选择主题 ─▶ 第 2 屏：配置模型 ─▶ 主界面：对话框发消息，Agent 完成视频任务
                                                              │
              高级模式（IDE：Monaco/时间线/QA）◀── 侧栏入口 ──┤ 设置中心（全面）· 可视化面板
```

- 用户对 Agent 说「做一个 30 秒的产品介绍视频，产品是 XXX」；
- Agent（规划 → 写 DSL → compile.run → render.preview → test.run → render.final）全自动完成，聊天流内联展示每步（任务卡 / 代码 / 预览帧 / QA 结果 / 最终 MP4）；
- 用户随时点头/否决（权限门控）、切到 IDE 模式精修。

## 2. 首启向导（2 屏，可跳过、可重跑）

### 第 1 屏 · 主题选择
- 8 个主题卡：`Midnight 深空` `Graphite 石墨` `Amber 琥珀` `Forest 暗绿` `Rose 玫红` `Sand 暖沙`（浅色）`Paper 纸白`（浅色）`Daylight 日光`（浅色）
- 每卡实时迷你预览（用真实组件渲染缩略），点击即全局生效（CSS variables：--bg/--panel/--accent/--text…）
- 底部「稍后再选」→ 默认 Midnight；主题随时在设置中改

### 第 2 屏 · 模型配置
- 供应商网格（消费 `@videoos/model-hub` 的 `loadCatalog()`；Agent Kit 未交付前用**内置兜底目录**——与 SPEC 附录 A `ProviderConfig` 一致的静态 8 家：openai/anthropic/deepseek/zhipu/qwen/moonshot/doubao/ollama + custom 自定义端点）
- 每家卡片：名称(中英)/默认 baseUrl（可改）/API Key（password 输入，存 settings，绝不入 git）/模型下拉（catalog 快照 + 「拉取模型列表」按钮）/「测试连接」按钮（model-hub `testConnection()`；兜底版用最小 chat 请求）
- 测试结果内联：延迟/模型数/错误分类与 hint；至少配好 1 家才能「进入主界面」（或「跳过，用演示模式」→ manual provider）
- 支持多家：默认模型 + 可选「规划用/对话用」分角色

## 3. 主界面 · 对话式 Agent

布局（三栏，可折叠）：
```
┌────────┬───────────────────────────┬───────────────┐
│ 会话列表 │  对话流（消息/任务卡/artifact） │  可视化面板      │
│ + 新对话 │  底部输入框（发送/停止/附件）    │  预览·时间线·管线 │
│ Skills  │                            │  用量           │
│ 设置入口 │                            │               │
└────────┴───────────────────────────┴───────────────┘
```

- **会话**：服务端持久（server API：sessions CRUD + 消息历史）；每会话绑定一个 videoos 项目目录
- **消息流**：用户消息 / Agent 回复（markdown）/ **任务卡**（Agent 每步一张：规划→写码→编译→预览→QA→渲染，含状态徽章与耗时）/ **artifact**（DSL 代码块、预览帧 PNG、QA 断言表、最终 MP4 内联播放）
- **Agent 循环**：复用 `@videoos/agent` executor + 31 VAP 工具；v0.2 新增 chat 会话编排（system prompt 含当前项目上下文 + 选中 skills 注入）
- **流式**：回复文本与任务卡状态经 server WS 推送（复用 render-progress 的 WS 基建，新增 `agent` 频道）
- **权限门控**：`shell 类/文件删除类` 工具默认需用户在聊天里点确认（设置可调）
- **停止**：随时中断循环（SIGTERM 语义，保留已完成步骤）

## 4. Skills 与 MCP 面板

- 侧栏 Skills：`skills/` 目录（Agent Kit 交付后自动 5→25）列表 + 搜索 + 在对话中 `@skill` 引用或让 Agent 按 trigger 自选
- 侧栏 MCP（本地能力）：消费 `@videoos/mcp-host`（未交付前隐藏入口）；服务器启停/工具清单/白名单；工具调用走 host `callTool`，Agent 的工具列表可合并 MCP 工具（设置开关）

## 5. 设置中心（绝对全面）

九大类，左树右表单，全部即存即生效（server `settings` API + 桌面 userData 持久化）：

1. **通用**：语言(zh/en) · 主题（向导第 1 屏同款 8 选）· 启动行为（进上次会话/新对话/向导）· 关闭行为（退出/托盘）
2. **模型与供应商**：供应商 CRUD（向导第 2 屏同款）· 默认模型（对话/规划分角色）· 采样参数（temperature/maxTokens/topP）· 超时重试 · 代理(baseUrl 级) · Key 导入导出（明文警告）
3. **Agent 与自主性**：自主级别 L1 全确认–L4 全自动 · 最大迭代步数 · 工具权限矩阵（31 VAP + MCP 工具逐项 allow/confirm/deny）· 危险命令黑名单 · 渲染前确认开关
4. **渲染**：默认输出目录 · 分辨率/帧率/格式预设（1080p30/720p30/竖屏 1080×1920）· 硬件加速探测 · 渲染队列并发 · 失败重试
5. **MCP**：服务器列表（command/args/env/启停/白名单/超时）· mcp.json 导入导出
6. **Skills**：启用/禁用 · 自定义 skills 目录 · `@skill` 自动触发开关
7. **界面**：字号 · 消息密度 · 代码主题 · 动效开关 · 时间线拍点显示
8. **隐私与数据**：遥测开关 · 崩溃报告 · 日志级别与保留天数 · 会话保留策略 · 一键清除（对话/缓存/设置分级）
9. **高级**：配置编辑器（JSON 带校验）· 日志查看器 · 缓存统计与清理 · 恢复出厂

## 6. 可视化面板（右栏）

- **预览播放器**：当前会话最新项目的帧预览/播放（复用 studio 播放器组件）
- **时间线**：场景/beat 轨道，点击跳帧（复用既有）
- **任务管线**：本次 Agent 任务 6 步流水线（规划→DSL→编译→预览→QA→渲染），逐步点亮 + 耗时 + 失败分支红显
- **用量**：本会话 token 消耗（prompt/completion 累计）+ 渲染帧数/缓存命中率

## 7. 技术方案（增量，不推翻 v0.1）

| 层 | 决策 |
| --- | --- |
| apps/studio | 新增 `welcome/`（2 屏向导）、`chat/`（三栏主界面）、`settings/`（九类中心）；IDE 视图保留为「高级模式」路由 |
| apps/desktop | Electron 壳不变（sidecar + 桥）；userData 下持久化 `settings.json`（key 经 safeStorage 加密落 `settings.secure.json`） |
| @videoos/server | 新增：`/api/settings`(CRUD+schema) · `/api/sessions`(CRUD+消息) · `/api/agent/chat`(启动循环) · WS `agent` 频道（任务卡/流式文本/确认请求）· `/api/providers/test`(连通性) |
| 消费 Agent Kit | `@videoos/model-hub`（catalog/工厂/testConnection）与 `@videoos/mcp-host` 均为 optional peer：存在即加载，不存在走内置兜底 —— **主线进度不被并行项目阻塞** |

## 10. Agent 增强包（v0.2.1 · S7）— 普通模型的 Opus 级脚手架

目标：让普通模型（开源/小参数/低成本模型）也能稳定产出 Claude Opus 5.5 水准的代码视频。核心思路不是换更强的模型，而是**五层脚手架叠加**——把「从零写视频代码」变成「套模板、抄模式、按纪律验证」：

| 层 | 机制 | 交付物 |
| --- | --- | --- |
| 结构层 · 模板脚手架 | `template.list → inspect → apply`：8 个完整可编译视频模板一键套用，模型只改文案/颜色/数据常量 | `templates/` 8 模板 + 3 个 VAP 工具 |
| 细节层 · 动效模式库 | `pattern.search → get`：34 个可直接照抄的 DSL 动效片段（hook/节奏/文字/数据/画面/转场/结尾七类） | `knowledge-data.ts` + 2 个 VAP 工具 |
| 知识层 · 技能配方注入 | @skill 自动注入升级：Workflow + Anti-patterns 之外新增 **Recipes 代码配方**与 Goal（设置开关 `skills.injectRecipes`，默认开） | `skills.ts` |
| 准确层 · DSL 速查 | `dsl.reference` 九主题速查 + 系统提示「DSL 速查（引擎事实）」：单行文本/at.x 语义/效果方向/时间窗等 10 条硬事实 | `knowledge.ts` + orchestrator |
| 质量层 · 修复循环 | 系统提示「修复循环纪律」：compile → 单点修（≤3 轮）→ 预览关键帧 → test.run 全绿 → render.final | orchestrator + 既有 38 工具门禁 |

配套改动：

- **VAP 工具 31 → 38**：template.list/inspect/apply + pattern.search/get + skill.read + dsl.reference；权限分级：知识类全 PURE_INSPECT（L1 直通），template.apply CORE_MUTATION（L2+ 直通）
- **工具消息上限 4000/512 → 12000/8000**：技能配方与模板源码可完整到达模型上下文（此前 512 字符截断会摧毁代码块）
- **可视化补全**：右栏新增「时间线」页签——场景轨道/beat 行/转场标记/时间标尺，点击即跳帧并联动预览播放器（S5 规格的第 4 组件补齐）
- **设置补全**：供应商采样参数（temperature/maxTokens/topP/timeoutMs）schema→provider→UI 端到端；Skills 页「注入配方代码」开关
- **MCP 一键导入**：`GET /api/mcp/presets` + 设置页「导入推荐服务器」——28 个内置服务器预设（15 个纯计算类默认启用，139 个本地工具即刻可用），文件系统类预置 `MCP_*_ROOTS="."` 一键开启
- 测试：全仓 943/943 绿（867 基线 + 17 模板 + 38 知识 + 16 设置 + 5 集成）
